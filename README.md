# Breast-Cancer-Classification-using-Support-Vector-Machine- </br>
## •	Technologies: Python, Scikit-learn, NumPy, Pandas, SVM (SVC — Linear Kernel), sklearn.datasets (WDBC) </br>
## •	Engineered a binary breast cancer classification system using Scikit-learn's SVC with a linear kernel on the Wisconsin Diagnostic Breast Cancer dataset (569 samples, 30 features); implemented an 80/20 stratified train-test split achieving high accuracy on both training and test data for malignant vs. benign tumor prediction </br>
## •	Developed an end-to-end predictive pipeline leveraging Pandas for data ingestion and exploratory analysis (null-value checks, statistical measures, label distribution), NumPy for array reshaping, and a real-time inference module accepting raw 30-dimensional tumor morphology inputs to output actionable clinical predictions </br>
## •	Designed an offline-friendly, India-specific cancer hospital recommendation feature integrating Haversine geospatial distance computation; incorporated a curated database of 15+ regional oncology centers (Tata Memorial, AIIMS, etc.) with city-based and coordinate-based retrieval, enhancing the tool's real-world utility for patient guidance <br>
